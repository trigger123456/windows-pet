# 产品方向

## 核心定位

Windows Pet 是一个工作流感知型 Windows 桌宠。它不是循环播放动画的桌面装饰物，而是用轻量、不打扰的方式陪伴用户工作：通过台词、提醒、托盘菜单和小型工具感知当前工作节奏，并在合适时机提醒用户继续主线、整理改动或休息。

## 当前阶段

项目处于 Web 原型 + Electron 桌面壳验证阶段。

- Web 原型用于调试状态机、事件队列、台词和行为参数。
- Electron 桌面入口用于验证真实桌面能力。
- 当前角色表现为单张静止立绘：`src/assets/character-v2.png`。
- 当前不使用像素图、不使用动作帧、不使用动作帧预览页。
- 设置窗口和配置持久化已接入。

## 当前 MVP

- 透明无边框悬浮窗口
- 始终置顶
- 托盘菜单
- 拖拽窗口
- 贴边吸附
- 透明区域鼠标穿透
- 独立设置窗口
- 窗口位置、缩放、透明度和行为参数持久化
- 开机启动开关
- 基础状态：待机、散步、专注、休息、庆祝
- 事件队列、随机台词、休息提醒、番茄钟
- 工作流事件模拟
- Git 工作区检查和后台监控
- `npm run build` / `npm run test` 入口
- 常见 AI 编程工具进程检查

## 用户价值

- 降低工作流中断后的恢复成本。
- 用轻提示提醒用户保存、提交、整理改动。
- 在长时间专注后提醒休息。
- 通过角色化反馈让构建、测试和提交结果更有陪伴感。
- 保持桌面常驻但尽量不遮挡鼠标操作。

## 技术路线

当前路线：Electron + 原生 HTML/CSS/JS。

选择 Electron 的原因：

- 当前环境已有 Node/npm，落地最快。
- 可直接接入文件系统、Git、脚本运行和托盘能力。
- 与现有 Web 原型共享渲染层和状态机。

暂不默认切换到 Tauri：

- 当前环境未安装 Rust/Cargo。
- Tauri 适合后续追求更小体积时重新评估。

长期可选路线：

- Electron：继续加强桌面能力和工作流集成。
- Tauri：在 Rust 工具链准备好后评估体积优化。
- C# WPF/WinUI：如果要做深度 Windows 原生体验，可作为长期路线。

## 近期优先级

1. 优化静止立绘的透明背景、桌面尺寸和气泡位置。
2. 完善状态队列、台词优先级和提醒节奏。
3. 更细的测试 / 构建结果解析。
4. 更深入的 AI 编程工具状态集成。
5. 真实安装环境验收。
6. 如需动画化，再重新确认角色表现路线。
