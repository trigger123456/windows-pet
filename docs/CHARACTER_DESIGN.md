# 角色设计：静止立绘看板娘

当前角色使用单张静止立绘作为桌宠主资产：

- 主资产：`src/assets/character-v2.png`
- 表现方式：PNG 立绘 + CSS 分层关键帧拟态
- 当前不使用像素图
- 当前不使用动作帧
- 当前不使用动作帧预览页

## 气质

- 二次元美少女桌宠
- 冷静系游戏看板娘
- 安静陪伴
- 轻微吐槽
- 不尖锐、不冒犯

## 行为表现

当前状态变化会影响：

- 气泡台词
- 状态标签
- 事件队列
- 提醒节奏
- 工作流反馈
- 外层身体动作
- 内层呼吸、重心与轻微旋转
- 角色遮罩高光

状态变化不切换图片，通过外层与内层独立 `transform` 模拟 Live2D 风格的软运动。这不是真正的 Live2D 模型，因此暂不支持独立眨眼、口型或头发物理。

## 后续方向

如果后续要继续增强角色表现，优先考虑：

1. 优化当前立绘的透明背景和边缘。
2. 调整桌面显示尺寸、阴影和气泡位置。
3. 增加少量表情差分。
4. 拆分眼睛、嘴、前后发和身体图层，再评估接入 Live2D Cubism。
